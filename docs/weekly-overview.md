# 周概览

入口：主窗口左侧“月历”下方的“周概览”。每周固定周一至周日，默认显示本周，适合周一组会查看上一周完成情况及本周安排。

- “上一周 / 下一周”切换周范围，“返回本周”回到当前周；范围显示完整起止日期，支持跨月、跨年。
- 每天一行，任务仅显示单行标题和右侧完成框；超时标题保留红色，完成项保留删除线。默认展示前2项，右侧“+N”展开其余，长标题可悬停或打开详情查看。
- 顶部改为一行简要统计，移除大型统计卡片和进度条。分类/状态筛选同时影响每日列表及统计。
- 点击任务标题打开原详情；右侧方框可完成或撤销，删除仍先确认。有未完成子任务时保留原确认逻辑。
- 今天及未来日期可通过当天行右侧“＋”添加任务，保存后留在周概览；过去日期只查看和编辑，沿用原新建日期限制。

分组优先用安排日期，没有安排日期时用截止日期（精确截止按本地日期）。没有日期的心愿不参与；已删除记录不参与。任务按所属日期归周，不按实际完成时间或今日超时列表重新归周，因此上周未完成任务仍在上周概览，今天页面继续显示其超时状态。

复用唯一Pinia任务Store及Rust LocalService的现有任务快照、revision同步。切换周和筛选只计算已同步数据，不新建数据库、IPC、调度器或写入记录。重复任务仅显示实际生成的实例，与月历一致。停留在本周时跨周自动跟随；主动浏览历史或未来周时保留所选范围。

本轮执行TypeScript/格式检查和Release、NSIS打包，不运行自动化测试、启动应用或GUI验收；实际小窗口布局及交互待体验确认。

2026-11-02 简化：空日期的任务栏留白，不显示“暂无任务”等说明。默认每行仅两项用于减少页面高度；多任务展开后正常滚动，不承诺任意任务量都能单屏显示。

星期文字为17px，日期为11px；任务按保存的顺序显示，勾选完成不再自动移到最后。分类/状态筛选仍正常生效。
