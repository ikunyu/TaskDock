# 悬浮小组件锁定（1.1.1）

小组件展开和收起时，右上角都有锁形按钮。点击后整个小组件鼠标穿透，鼠标点击、滚动等操作由下方窗口接收，也不能再拖动、缩放或勾选小组件任务。

解除锁定：右键 Windows 系统托盘中的 TaskDock 图标，选择“解锁悬浮窗”；或者在主窗口“软件设置 → 外观与桌面”取消“锁定悬浮窗（鼠标穿透）”并保存。锁定状态会保留到下次启动。锁定与置顶、显隐互相独立。

不透明度可设置为 **20%～100%**，默认100%，点击保存桌面设置后生效。任务列表、页签、字号和原有尺寸规则保持。

## 实现

- 使用已锁定 Tauri v2 的 Rust `set_ignore_cursor_events` 和 `set_focusable`，不开放通用前端窗口控制权限。新增的 `lock_widget` 仅允许 widget 调用，复用 desktop-widget 权限组；拖动、缩放保留原同步命令。
- 在同一 UI 线程回合设置鼠标/焦点状态并最后应用 Windows layered alpha，避免解锁时原生样式更新清除不透明度。窗口布局、显隐及恢复后重新应用样式。
- 复用 DesktopSettings、LocalService、桌面操作 gate 和 revision 事件。托盘解锁只修改 widget_locked，事务同步 revision；不覆盖其他窗口的设置草稿。原生应用或数据库写入失败时尝试恢复原状态，返回错误。
- Schema 8 新建兼容约束的设置表并完整复制设置，增加 widget_locked（默认0、仅0/1），不透明度约束改为20–100；备份目录保留全部记录并支持Schema8。0001–0007迁移原文不变。下行仅供开发者在显式事务内使用，不兼容新设置或存在Schema8备份时拒绝回退。
