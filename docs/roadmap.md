# 六阶段计划

| 阶段                 | 实现范围                                                      | 出口条件                                           |
| -------------------- | ------------------------------------------------------------- | -------------------------------------------------- |
| 1 项目初始化         | 环境核对、文档、三窗口、SQLite 迁移、主题、错误日志、测试骨架 | 前端/原生构建及基础启动检查；记录环境阻塞          |
| 2 任务管理           | 四视图、CRUD、分类、计划/截止、优先级、子任务、事务历史       | 业务边界测试、持久化与窗口同步验收                 |
| 3 桌面集成           | 悬浮交互、窗口状态、多显示器、快捷键、托盘、自启动            | Windows 10/11、混合 DPI、断开屏幕恢复实测          |
| 4 提醒重复           | 提醒状态机、睡眠恢复、稍后提醒、重复规则和幂等实例            | 假时钟测试、跨月/闰日/时区、重启恢复、系统通知实测 |
| 5 数据保护和辅助功能 | 备份、JSON/CSV、安全恢复、月历、搜索、历史浏览                | 损坏备份拒绝、恢复回滚、CSV 注入处理、大数据检索   |
| 6 综合测试与发布     | 回归、安全、性能、安装器、签名和发布                          | 可追溯测试报告、Windows 安装升级卸载、已知风险清单 |

阶段必须顺序推进，每阶段完成后提交功能、文件、决策、实际命令与结果、问题风险和下一阶段建议。第一阶段已验收，第二阶段经用户授权实施，结果见 stage-2-report.md。当前交付到第二阶段并停止，第三阶段需要用户另行决定。
