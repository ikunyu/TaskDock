## 修复过的失败

1. 初期 Rust 命令因缺少 link.exe 失败；临时工具准备期间也出现缺 msvcrt.lib 的链接错误。补齐官方工具和库后，最终完整工具链复验通过。
2. Vite 默认监听工具链和 Rust 产物时出现 EBUSY，已排除 .tools、src-tauri 和 artifacts。
3. 快速输入首次显示时焦点可能停在文档层，Esc 未被局部元素接收。改用窗口级键盘监听，并在窗口获焦时聚焦输入框，原生复验通过。
4. 首次独立 release 启动出现页面早于 Rust 服务注册的 IPC 竞态。三个窗口改为 create=false，在 setup 注册服务后通过 Tauri v2 from_config 创建；重建后独立启动及三个生产窗口验收通过。

## 技术决策

仅在 Rust 层使用 rusqlite bundled SQLite，不暴露 SQL 或任意文件系统 API。已应用迁移保存原 SQL，并通过 LF 文件规范避免跨平台换行漂移。迁移失败完整回滚，损坏/高版本数据库不自动替换。主题与 revision 同事务提交，发事件后前端忽略旧版本，聚焦时重新读取。

三个窗口共用唯一 LocalService。仅主窗口可改主题；主窗口可打开子窗口，小组件只可打开快速输入；子窗口仅可隐藏自身。主窗口关闭退出进程，子窗口关闭隐藏。第一阶段保留原生标题栏，不实现托盘常驻。
