# 数据管理使用说明

当前版本1.0.0。以下描述实现的交互；本阶段未启动软件或执行运行验收。

## 备份

打开软件设置 → 数据管理。自动备份默认开启，间隔24小时、保留最近30份自动备份。周期可设1–8760小时，保留1–365份；修改后点击保存。应用完全退出时不执行备份，重新运行后检查是否到期。失败后保留旧备份并显示错误，自动重试间隔至少15分钟。

“立即备份”创建手动备份，校验和完整性检查通过后才显示成功。“打开备份目录”打开EXE所在目录下data/backups文件夹，不允许自定义任意备份路径。

命名：`taskdock-backup-YYYYMMDD-HHMMSS-UUID.db`（UTC），配套`.db.json`清单包含SHA256、时间、大小和Schema。复制保管时成对保留，不手工改名或修改校验值。临时/未发布文件不出现在列表。自动清理只影响超出保留量的自动备份，不删除手动和恢复前安全备份；清理失败会保留文件并提示。

## 恢复

在列表选择恢复，确认备份时间。恢复会替换当前全部数据，并重置三个窗口的未保存草稿；请先完成其他窗口的编辑。确认后先创建当前数据库安全备份，再校验、兼容迁移副本、暂停写入和调度、关闭连接后替换文件。

成功后重新加载任务、主题和窗口设置。快捷键或开机启动等系统设置若未能应用，会显示警告，可打开设置处理。恢复前安全备份保留，可再次选择恢复。

损坏、校验不符、更高程序版本或不符合表结构的备份会被拒绝。文件被占用或替换失败时，程序尝试回退；若提示需重启，保留数据库、安全备份、restore-journal.json及隐藏回退/隔离文件，不要删除数据库解决问题。下一次初始化会依据恢复日志处理未提交操作。

恢复会保留本机历史提醒发送去重记录，因此恢复旧状态不会为了旧提醒再次弹系统通知。已经交给Windows的通知不保证撤回。

## 导出

- JSON完整导出：包含任务管理、设置、规则、提醒、历史、备份目录记录及格式/Schema元数据。当前不提供JSON导入；数据库恢复使用完整SQLite备份。
- CSV全部任务：包含软删除任务，保留原完成状态并另列删除时间。
- 搜索页“导出当前筛选CSV”：导出全部匹配项，不仅当前50项；默认排除已删除。

保存位置由原生对话框选择，不能覆盖应用数据库目录；已有目标文件需要确认。CSV为UTF-8 BOM，字段正确引用和换行，潜在公式文本加单引号作为数据。精确时间导出为UTC字符串，纯日期保持日历日期。

## 日历与搜索

月历不替代原计划视图。按任务计划日期归日，无计划时按截止日期（精确时间转本地日期）归日。选择日期查看列表，可直接添加该日任务；支持分类、优先级/完成/逾期标记。只展示实际生成的重复任务，不预览无限未来规则。

搜索覆盖标题、描述和子任务，支持组合条件、清空筛选、每页50项；关键词中的`%`、`_`和反斜杠按普通文字处理。纯日期不做UTC转换，精确截止范围按本地日期解释。

操作历史浏览功能已移除。原审计数据及事务写入保留，完整备份、恢复与JSON导出仍包含这些记录；不会因为移除页面而删除旧数据。

## 数据位置

数据管理页显示实际数据目录。任务和全部数据库设置在EXE旁data/taskdock.sqlite3，备份在data/backups；把软件安装到非C盘可写目录即可将任务数据放在该盘。升级同一目录不会替换data；移动软件需退出后带上整个data。首次迁入旧AppData数据只对新盘暂存副本做迁移与校验，旧数据库和备份均保留，失败不切换到空库。
