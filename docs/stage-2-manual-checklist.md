# 第二阶段手动验收步骤

用户于 2026-10-28 接管手动测试，自动 UI 操作已停止。当前 TaskDock 为最终 0.2.0 Release，主窗口和两个子窗口已经打开，主题当前为深色。现有两条“阶段二验收”记录可保留；以下建议新建带“手测”前缀的数据。

每步可记录“通过 / 失败 + 实际看到的结果”。不用操作数据库文件。

## 1. 分类与今日任务

1. 主窗口左侧“分类管理”→输入分类名称“手测分类”→“保存分类”→关闭对话框。
2. 左侧“今天”→右上“新建任务”→标题填“手测·主任务”，描述任意，计划日期选今天，优先级选“高”，分类选“手测分类”。
3. 截止方式选“仅日期”，截止日期选明天；点击两次“添加子任务”，分别输入“第一步”“第二步”→“保存任务”。
4. 预期：任务出现在今天，显示分类、优先级和 0/2 进度。侧栏“悬浮小组件”中也显示同一任务。

## 2. 四视图与逾期

1. 点击“手测·主任务”标题→计划日期改成昨天→保存。
2. 预期：仍在“今天”，标注“计划逾期”。
3. 再改成明天→保存，点击左侧“计划”：应出现该任务，“今天”不再显示它。
4. 再清空计划日期→保存，点击“收集箱”：应出现；已有截止日期不改变这个归属。
5. 将计划日期改回今天以继续下列测试。截止可改为“无截止”并保存；再打开确认允许为空。如需测试精确时间，选“精确时间”，保存后重开应保持所选本地时间。

## 3. 父任务确认与窗口双向同步

1. 在悬浮窗口勾选“手测·主任务”。
2. 预期：出现未完成子任务确认。先“取消”，任务保持未完成；再勾选并选择“仍然完成”。
3. 预期：主窗口今天列表移除，左侧“已完成”中出现任务并保留完成时间；子任务不会被自动勾选。
4. 在主窗口“已完成”中取消任务勾选。
5. 预期：回到今天；悬浮窗同步取消勾选，不需手动刷新。

## 4. 子任务编辑与进度

1. 主窗口打开详情，修改子任务标题，使用 ↑/↓ 调整顺序，保存后重开检查顺序。
2. 勾选一项子任务并保存：进度应为 1/2、50%。
3. 勾选另一项并保存：进度应为 2/2、100%，父任务仍未完成。
4. 删除其中一项再保存：应为 1/1、100%。若需要，可以再新增一项验证增删。

## 5. 软删除、恢复和分类删除

1. 在主窗口列表点该任务右侧 ×（或详情“移至已删除”并确认）。
2. 预期：常规视图及悬浮窗不显示该任务；左侧“已删除”中能看到它。
3. 点击“已删除”中的“恢复”：任务回到今天，子任务内容及状态保留。
4. 打开“分类管理”，删除“手测分类”并确认。
5. 预期：任务仍存在，分类变成无分类；子任务及完成进度不受影响。

## 6. 快速输入

1. 左侧“快速输入”→填“手测·快速记录”，不勾“安排到今天”→“添加任务”。
2. 预期：输入清空并提示成功，主窗口收集箱出现该任务。
3. 再填“手测·快速今日”，勾“安排到今天”→添加。
4. 预期：主窗口今天和悬浮窗都出现。点击悬浮窗刷新按钮不会重复创建记录。

## 7. 草稿、输入校验与主题

1. 新建任务，标题只输入空格，尝试保存：应拒绝创建。
2. 编辑已有任务但不保存，按 Esc：应要求确认是否放弃修改。选择继续编辑/取消后草稿应保留。
3. 保持主窗口详情打开，在悬浮窗改变同一任务完成状态：详情应提示其他窗口已修改，保留草稿，禁止旧版本直接覆盖；可选择放弃草稿并重新载入。
4. 主窗口左下“外观”依次选择“明亮”“深色”：三个窗口应同步，文字、进度和按钮均可辨认。需要恢复原偏好可选“跟随系统”。

## 8. 重启持久化

1. 确保所有需要的编辑已保存，关闭主窗口（应用会退出，不会留在托盘）。
2. 双击 `F:\tododock\src-tauri\target\release\taskdock.exe`。
3. 预期：任务、子任务、计划/截止、完成状态、分类及主题仍保留，页脚为 Schema 2；没有重复任务。

## 不必手动破坏环境的项目

迁移失败回滚、审计写入失败、保存失败草稿、无效外键和多连接快速并发已在临时数据库/模拟 bridge 自动测试。不要删除真实数据库、修改迁移表、断电或故意损坏文件。Windows 10、混合 DPI、多屏和跨夜长跑仍为独立待验收项。

若发现问题，请提供步骤编号、实际结果、预期结果，以及当时使用的窗口；如有错误代码一并记录。手测数据可通过“已删除”软删除，不需要硬删除数据库记录。
