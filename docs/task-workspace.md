# TaskDock 1.0.0 任务与心愿单

## 新的入口

- **任务**：同一个页面内切换“今天”和“未来事项”，共用“新建任务”按钮。任务必须有安排日期，新建仅允许今天及以后，默认今天；未来事项到了当天自动进入今天，过去未完成事项继续显示在今天。
- **心愿单**：记录想买电脑、想去旅行等个人愿望，没有固定日期。通过“添加心愿”创建，实现后勾选右侧方框，删除线记录继续保留，可再次点击撤销划掉。心愿不自动转成有日期的任务，也不进入任务的已完成列表。
- **已完成**：保留有安排日期的任务完成记录及撤销完成操作。

快速输入窗口作为正式任务的快捷添加方式，默认今天，也可以选未来日期；个人愿望通过主窗口心愿单添加。

## 数据兼容

本次只调整前端入口、编辑校验和视图过滤，不新增数据库或修改既有迁移，仍使用 Schema 5。沿用已有字段：有 planned_date 的事项为有日期任务，无 planned_date 的事项展示为心愿；原收集箱和原来无日期的已完成记录均保留在心愿单中，已完成状态以删除线显示。

新建心愿不展示排期、截止和提醒表单。旧的无日期事项如果已经保存截止或提醒配置，详情仍提供这些字段，避免隐藏和丢失既有设置。删除改为确认后永久删除，旧软删除记录不清理；分类、审计及多窗口 revision 同步沿用原服务。

任务和心愿改用右侧方框：未完成为空框，成功完成后显示对勾，再次点击撤销；不改动真实数据，只有用户点击保存或状态操作才写入。

## 超时任务

未完成任务有精确截止时间时，达到该时刻即标记“超时任务”；仅有截止日期则当日本地自然日结束后标记。未设截止时间/日期时，安排日期过后仍未完成即超时。有未来截止但安排日期已过的任务仍显示“计划逾期”，尚不标为超时。没有排期或截止设置的普通心愿不受影响。

超时项优先显示在主窗口今天和悬浮窗今日列表；原本安排在未来但截止已经到期的任务也会进入今天，不再留在未来页。收起的悬浮窗用红色“超时 · 标题”，展开后显示完整“超时任务”标记。旧版无计划日期但已有截止配置的心愿，超时后也在今日额外展示，原心愿记录保留。

完成后取消超时标识；展开悬浮窗保留今天完成的项目以便撤销。修改截止时间、撤销完成、重新启动或休眠恢复后，按当前保存数据和本地时钟重新判断。超时是派生展示状态，不覆盖 pending/completed，不修改任务日期、数据库版本、提醒配置或重复规则。

每个任务 Store 增加一个下一截止/午夜的一次性计时器，沿用30秒及窗口聚焦校时兜底；不新增后台服务、额外写库或持续查询。计时器随 Store dispose 清理。WebView 后台节流或系统休眠可能延迟重绘，恢复/聚焦会重新判断，真实系统行为待验证。

## 新建日期与右侧完成框

新建任务的安排日期、截止日期/时间、指定提醒及重复结束日期只接受用户本地今天及以后；同一天的时刻仍可选择。月历过去日期可查看原任务，但“在此日期添加任务”禁用。已有任务编辑保留历史日期，不批量改日期、不影响超时、重复实例补齐或旧备份恢复。

原生日期控件最小日期、保存前校验、Rust创建IPC校验共同限制手动输入和跨午夜草稿。限制仅作用于用户新建，数据库通用历史校验和重复引擎不修改。

列表和展开悬浮窗的任务行右侧使用方框，点击保存成功后显示对勾，再点击撤销。方框带checkbox语义、键盘操作及完成/撤销的辅助说明。未完成子任务仍需确认；取消确认或保存失败时不提前打勾。收起悬浮窗继续只显示标题/超时标记。

## 快速选日期

安排日期、纯日期截止、重复结束日期和快速输入日期复用 DateField。保留原生日期输入及校验；右侧日历按钮使用内联月面板，可直接输入年份、选择月份、翻月或点选日期，另有今天/明天/一周后快捷选择。面板不覆盖其他表单，点外部或Esc收起；Esc关闭面板时不关闭详情/快速输入窗口。限制外的日期和月份禁用；历史编辑保留原最小日期。没有改动数据库、IPC或日期时区语义。
