# TaskDock V1.0 需求基线

2026-11-02 最新界面要求：取消搜索与筛选模块入口及界面；悬浮未来事项按周一至周日分组；周概览采用紧凑逐行布局，默认每日两项、其余展开。各处没有记录时留白，不显示插图或“暂无”/引导提示；错误及危险确认保留。下方历史阶段搜索/空状态需求不再作为当前界面要求。

2026-11-02 新增周概览：周一至周日为一周，主窗口独立入口，默认本周；支持前后周、返回本周、每日任务分组、完成与超时统计及分类/状态筛选。保留月历和原任务视图，新建日期限制、任务详情及多窗口同步不变。

当前交互调整：用户新建任务的日期只能选本地今天或未来日期，月历过去日期仅查看，不新增；已有任务可保留历史日期。完成操作为任务行右侧空框，成功完成后显示对勾，再次点击撤销；未完成子任务的确认和保存失败回退保留。

当前超时规则：未完成任务达到精确截止时刻、纯日期截止的次日或无截止且计划日期已过时，标为“超时任务”。主窗口今日与悬浮窗今日优先展示，未来页排除已超时项；完成后消除标记。普通无日期心愿不受影响。

2026-10-30 当前产品调整：不再展示“已删除”页面；列表与详情的任务删除需明确确认，随后永久删除，无法撤销。旧软删除记录保留，不做自动清理。下方第一/第二阶段的软删除与恢复要求为历史阶段范围，当前交互以此调整为准。

当前用户范围调整：操作历史浏览功能已取消，不再提供全局/单任务页面或查询 IPC；保留既有审计表、事务写入和备份兼容。下方原阶段历史需求只作为开发过程基线，当前功能范围以功能总览为准。

目标平台为 Windows 10/11，使用本地 SQLite，不引入账号或云服务。前端为 Vue 3 + TypeScript + Pinia + Vite，桌面宿主为 Tauri v2 / Rust。

## 第一阶段验收边界

- 建立三个真实 Tauri WebviewWindow：main、widget、quick-entry。main 默认显示；另两个由主窗口按钮打开，关闭后隐藏，可再次打开。
- 悬浮窗口初始内容区为 320×400 逻辑像素，可使用系统边框拖动缩放；完整位置恢复、透明度和置顶控制留到第三阶段。
- 显示四类任务视图的空状态和详情抽屉结构；快速输入仅布局预览，不假装保存任务，不插入示例任务。
- SQLite 打开、版本化事务迁移、基础设置持久化；主题通过统一 Rust 服务和事件在窗口间同步。
- 错误可见、可恢复重试；本地日志有大小/保留限制，禁止记录任务正文和敏感路径。
- 完成适用的类型检查、构建、测试，准确记录无法执行的验证。

## 第二阶段验收边界

- 任务 CRUD、完成/撤销、软删除与恢复；分类增改删、筛选；子任务聚合编辑、排序和完成进度。
- 收集箱为未完成且无计划日期；今天为未完成且计划日期不晚于本地今天；计划为未来未完成；已完成保留完成时间；常规视图全部排除软删除项。
- 计划日期和仅日期截止均为日历日期。精确截止为 UTC 时间点；无截止合法。截止逾期独立显示，不改变任务的视图归属。
- 悬浮窗读取真实今日任务，保留当日计划的已完成项，以及过去计划但今天完成的项，支持撤销及整体完成比例。快速输入可创建收集箱/今天任务。
- 数据库是唯一真相源；Schema 1 升级到 Schema 2，不重建库。每次业务写入与聚合审计同事务，乐观锁防止多个窗口覆盖。
- 保存失败保留草稿；跨窗口修改要求重新载入；有未完成子任务时完成父任务需要确认；全部子任务完成不自动完成父任务。
- 分类删除保留任务。历史数据已记录，但历史浏览仍属第五阶段。
- 不实现托盘、全局快捷键、自启动、透明度/置顶/位置记忆、提醒、重复、备份恢复、月历高级搜索及安装器。

## 核心业务约束

计划日期和仅日期截止是用户所在时区的日历日期，精确截止/提醒/完成时间是 UTC 时间点；不能用截止代替计划日期。优先级为 none/low/medium/high。完成父任务有未完成子任务时必须确认。子任务进度由子任务状态计算，不单独维护浮点进度字段。

重复规则与任务实例分离，以规则 ID + occurrence_key 唯一约束实现幂等。每次任务修改、历史写入、重复生成和提醒状态变更必须在同一业务事务内完成。多窗口只调用一个 Rust 任务服务，不能各自读写数据库。事件表示数据失效通知，持久化数据库始终是真相源。

数据恢复必须先验证格式和版本，先备份、再事务导入，禁止未经明确允许删除或覆盖用户数据。提醒、托盘、快捷键、自启动和安装通知必须进行 Windows 真机验收。

## 第三阶段验收边界

托盘及关闭行为、默认Ctrl+Alt+T及修改/冲突处理、widget拖动缩放（260×220至600×800，默认320×400）、60–100%不透明度、显隐/置顶、几何记忆与工作区恢复、默认关闭的显式自启动、统一设置和单实例。默认关闭主窗口隐藏到托盘；显式退出清理OS资源及数据库。

开机启动使用用户级注册和--background，无管理员权限或后台服务。第二阶段冲突手动复现见stage-3-manual-checklist.md；工具激活失败不无限重试，不判为软件问题。Windows 10/其他DPI/多屏与真实登录必须按实际设备验收。系统通知、提醒、重复、备份、月历搜索、历史界面与安装器/签名继续留后续阶段。

## 第四阶段交付口径（2026-10-29）

按本次用户指令实现提醒、系统通知、重复任务和后台调度源码。支持明确取消提醒，沿用任务pending/completed状态；没有引入新的“取消任务”状态，停止某任务可取消提醒或软删除。批量通知、默认32天提前实例、日期/UTC分离、仅此一次/此后范围、应用内提醒和最小权限均已实现。系统实际行为、迁移/业务回归待验证；本次不运行测试、软件或Release构建，不以静态检查代替验收。第五阶段未开始。

## 第五阶段交付口径（2026-10-29）

实现本地一致性自动/手动备份、确认恢复、完整JSON/安全CSV导出、额外月历入口、组合搜索及审计历史界面。自动备份默认24小时/30份，仅应用运行时执行；手动/安全备份不随自动策略清理。恢复只选择固定目录已发布清单内的备份，不接受前端任意文件路径。日历显示计划日、无计划时的截止日和已生成重复实例；搜索/日历默认不显示软删除；历史保留删除/恢复和早期格式。数据导出与恢复后的OS设置同步失败必须明确显示。
