# TaskDock 1.0.0 功能总览

整理日期：2026-10-30。数据库版本：Schema 5。

按照本文的使用场景划分，当前软件包含 **11 大模块、59 项功能与基础能力**。数量按下方编号统计：同一功能在多个窗口中使用不重复计数，提醒时长选项不逐项计数，数据库表和 IPC 命令不算独立功能。

本清单根据现有源码及阶段交付文档整理，表示代码已实现的范围，**不表示 59 项均已完成运行验收**。当前 1.0.0 已合入月历查询修复和彻底删除功能，没有另外维护小版本。

## 一、任务生命周期（5 项）

| 编号 | 功能     | 当前行为                                                                                                                                 |
| ---- | -------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| 01   | 创建任务 | 从主窗口、快速输入或选定日历日期添加任务。                                                                                               |
| 02   | 编辑任务 | 在详情抽屉修改标题、描述及其他属性，明确保存。                                                                                           |
| 03   | 完成任务 | 点击任务右侧空框完成，提交后显示对勾；再次点击可撤销，保留父任务完成确认。                                                               |
| 04   | 撤销完成 | 将已完成任务改回未完成。                                                                                                                 |
| 05   | 永久删除 | 在列表或详情明确确认后移除当前数据库中的任务、子任务、提醒及任务历史，不能撤销或恢复。已有备份及旧版软删除记录保留，不再提供已删除列表。 |

## 二、任务属性、分类与子任务（7 项）

| 编号 | 功能                     | 当前行为                                                                                           |
| ---- | ------------------------ | -------------------------------------------------------------------------------------------------- |
| 06   | 计划日期                 | 安排任务在哪一天处理；新建只可选择今天及以后，默认今天；未来日期进入“未来事项”。                   |
| 07   | 独立截止日期或时间       | 可不设置截止；支持纯日期或精确时间，与计划日期分开。                                               |
| 08   | 优先级                   | 无、低、中、高四档，列表显示对应标记。                                                             |
| 09   | 分类管理                 | 新增、编辑和删除分类；删除分类不删除其任务。                                                       |
| 10   | 分类筛选                 | 在任务列表、月历和周概览中按分类查看。                                                             |
| 11   | 子任务编辑               | 添加、修改、移除、排序及勾选子任务。                                                               |
| 12   | 自动进度与父任务完成确认 | 根据子任务完成数量计算百分比；全部子任务完成不自动完成父任务，存在未完成子任务时完成父任务需确认。 |

## 三、任务视图与心愿单（4 项）

| 编号 | 功能     | 当前过滤规则                                                           |
| ---- | -------- | ---------------------------------------------------------------------- |
| 13   | 今天     | 今日及以前安排的未完成任务，并纳入截止超时项；超时项优先显示。         |
| 14   | 未来事项 | 计划日期在未来且尚未超时的未完成任务。                                 |
| 15   | 心愿单   | 不设固定日期的个人愿望，勾选右侧方框后保留删除线记录，再次点击可撤销。 |
| 16   | 已完成   | 展示完成记录及完成时间，支持撤销完成。                                 |

“任务”入口合并今天与未来事项两个页签，共用新建入口；心愿单和已完成为独立入口，已完成仅展示有安排日期的任务。上述入口均排除已软删除事项。达到截止仍未完成会标为“超时任务”，进入今日和悬浮窗并优先排列；收起时用红色“超时 · 标题”。没有截止设置则安排日期过后超时；不改变数据库的完成状态。

## 四、三窗口与桌面悬浮组件（8 项）

主窗口负责完整管理；另有悬浮窗口和快速输入窗口，三者复用同一个任务服务与数据库。

| 编号 | 功能               | 当前行为                                                                                                                                                                           |
| ---- | ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 17   | 快速输入窗口       | 输入标题和安排日期，默认今天或可选未来日期；可选分类，Enter 保存，Esc 隐藏。                                                                                                       |
| 18   | 任务悬浮展示       | 默认收起为按任务文字和条目实际尺寸自适应宽高的小窗，显示今日任务标题及已完成删除线；展开后显示今日/未来事项页签、进度及快速添加，仍支持完成、撤销和滚动；未来完成项保留原周/原位。 |
| 19   | 悬浮窗拖动         | 在标题空白区域拖动，按钮和输入控件不作为拖动区域。                                                                                                                                 |
| 20   | 悬浮窗缩放         | 右下角缩放；默认 320×400，最小 260×220，最大 600×800 逻辑像素。                                                                                                                    |
| 21   | 悬浮窗透明度       | 可在 60%～100% 不透明度之间调整。                                                                                                                                                  |
| 22   | 悬浮窗置顶         | 用户可开关，默认不强制置顶。                                                                                                                                                       |
| 23   | 悬浮窗显示与隐藏   | 可从主窗口、设置或托盘控制显隐。                                                                                                                                                   |
| 24   | 窗口状态与位置恢复 | 保存位置、尺寸和相关设置；恢复时按工作区与 DPI 处理，提供恢复默认位置。                                                                                                            |

悬浮窗会保留符合今日展示规则的已完成项，方便撤销及查看当日进度，其展示规则与主窗口只显示未完成项的“今天”视图略有不同。

## 六、提醒与后台调度（7 项）

| 编号 | 功能                   | 当前行为                                                                                         |
| ---- | ---------------------- | ------------------------------------------------------------------------------------------------ |
| 31   | 指定时间提醒           | 为任务设置本地日期和时间。                                                                       |
| 32   | 截止时提醒             | 可在任务截止时触发；纯日期截止按本地当天 23:59 处理。                                            |
| 33   | 提前提醒               | 支持提前 10 分钟、30 分钟、1 小时或 1 天，可组合。                                               |
| 34   | 稍后提醒               | 对到期提醒延后 10 分钟、30 分钟或 1 小时。                                                       |
| 35   | Windows 系统通知       | 显示任务标题和提醒内容，点击尽可能打开任务详情。                                                 |
| 36   | 应用内提醒中心         | 持久化查看到期提醒、稍后提醒或标记已知晓；作为系统通知不可见时的替代入口。                       |
| 37   | 后台调度与提醒状态管理 | 隐藏到托盘后继续运行；重启、休眠恢复后补齐，合并大量到期提醒；完成、删除或取消后停止待发送提醒。 |

完全退出期间不实时提醒，也不会通过额外 Windows 服务唤醒程序。撤销完成或恢复任务不会自动重发已取消的旧提醒，需要修改提醒时间后保存。

## 七、重复任务（6 项）

| 编号 | 功能               | 当前行为                                                                         |
| ---- | ------------------ | -------------------------------------------------------------------------------- |
| 38   | 每日重复           | 按每天或设定的天数周期安排。                                                     |
| 39   | 每周重复           | 选择星期，支持周间隔。                                                           |
| 40   | 每月重复           | 选择每月日期及月间隔；没有指定日期的月份使用最后一天。                           |
| 41   | 自定义间隔         | 按自定义天数重复。                                                               |
| 42   | 重复结束设置       | 支持结束日期或持续重复。                                                         |
| 43   | 重复实例与编辑范围 | 每次生成独立任务、保留完成历史；编辑支持仅此一次或此次及以后，也可停止后续重复。 |

重复需要计划日期。调度分批预生成实例，通过持久化游标、唯一约束和事务防止重复生成。删除某次实例不停止整个系列；彻底删除会保留该系列的日期排除项。

| 编号 | 功能             | 当前行为                                                                                            |
| ---- | ---------------- | --------------------------------------------------------------------------------------------------- |
| 44   | 自动备份         | 默认开启，每 24 小时一次，默认保留最近 30 份自动备份。                                              |
| 45   | 备份策略设置     | 设置开关、周期（1～8760 小时）和保留数量（1～365 份）。                                             |
| 46   | 手动立即备份     | 随时生成手动备份，不受自动备份清理策略影响。                                                        |

| 49   | 安全恢复         | 确认后先备份当前数据，校验和迁移备份副本，暂停写入、协调连接并替换，重新加载窗口与调度状态。        |

恢复失败回退、中断恢复、Windows 文件锁等已实现处理代码，但仍需隔离数据故障验证，不能视为已经验证可靠的数据恢复保障。

## 十、日历与周概览（3 项）

| 编号 | 功能         | 当前行为                                                                                  |
| ---- | ------------ | ----------------------------------------------------------------------------------------- |
| 53   | 月历浏览     | 上月、下月、返回今天；按天显示任务数量、完成、高优先级及逾期标记；空日期不显示提示。      |
| 54   | 周概览       | 周一至周日紧凑逐行展示；每天先显示两项，可展开；支持前后周、分类/状态、详情及按日期添加。 |
| 55   | 日历日期操作 | 点击日期查看任务、分类筛选、按选定日期添加任务，点击任务打开详情。                        |

月历优先按计划日期归日，没有计划日期时使用本地截止日期；重复任务只显示实际已生成的实例。常规视图不显示已删除任务；彻底删除后，该任务历史也会移除。

## 不单独计数的基础设计

- 默认本地 SQLite 保存，无账号、无云端依赖；数据目录与程序安装目录分离。
- 唯一 Rust LocalService、事务写入、revision 事件和乐观锁保持多窗口一致性。
- Schema 1～5 版本化迁移，保留已应用迁移，不通过删除旧库升级。
- 分窗口最小 IPC 权限，不向前端开放任意 SQL 或文件系统访问。
- 数据恢复具有维护锁、连接生命周期协调、恢复日志及历史提醒去重设计。
- 日志、可见错误、对话框键盘焦点和小尺寸布局处理。

## 当前验证状态与边界

当前统一 1.0.0 的 TypeScript 检查、Rust Release 编译及 NSIS 打包已成功；此前也完成过 Rust 静态检查、格式检查和相关 SQL 编译检查。最新整合没有运行自动化测试或 GUI 验收，未自动安装软件或操作真实用户数据库。用户反馈的月历错误已从源码定位并修复，但修复后的实际界面表现仍需确认。

需要后续体验或专项验证的重点包括：彻底删除及并发冲突、托盘/快捷键/开机启动、悬浮窗拖动缩放、多屏与 DPI、通知点击及系统屏蔽、休眠与时区变化、重复生成、真实备份恢复失败回退，以及安装升级和卸载保留数据。

当前不包含云同步、账号与团队协作、JSON/CSV 导入、周历/年历、软件自动更新及数字签名。系统通知是否展示受 Windows 设置影响；缺少 WebView2 时，内嵌引导程序仍需联网下载运行时。
