# TaskDock

面向 Windows 10/11 的本地桌面待办工作台。技术栈：Tauri v2、Vue 3、TypeScript、Pinia、Rust、SQLite。

当前版本 **1.1.1 / Windows Release 与 NSIS 安装包**。支持任务创建、编辑、完成与撤销、确认后永久删除，任务工作区、心愿单、分类、计划与截止、优先级和子任务。主窗口、默认宽200、高度按内容调整的悬浮窗口及快速输入窗口共用 Rust LocalService 与 SQLite，事务提交后以 revision 事件同步。保留第一阶段明暗主题、受限 IPC、迁移和日志错误处理。

新增系统托盘、全局快捷键、悬浮窗拖动缩放/透明度/置顶、窗口状态记忆、工作区恢复、开机启动及单实例。默认关闭主窗口隐藏到托盘，托盘或软件设置可显式退出。

## 安装

Windows x64安装包见 `src-tauri/target/release/bundle/nsis/TaskDock_1.1.1_x64-setup.exe`，主程序见 `src-tauri/target/release/taskdock.exe`。当前用户安装，缺少WebView2时需联网安装运行时；本版未签名，尚未执行安装或功能验收。详见[安装与使用说明](docs/installation.md)。

## 使用

悬浮窗右上角锁形按钮可开启鼠标穿透；再次点击锁形按钮即可解锁，也可右键托盘选择“解锁悬浮窗”或在设置中取消锁定。不透明度支持20%～100%，锁定状态重启保留。见[锁定与解锁说明](docs/widget-lock.md)。

空列表直接留白，取消空状态插图、引导文案及装饰标语；实际错误、未保存草稿和危险操作确认保留。

- 主窗口“任务”入口包含“今天 / 未来事项”两个页签，共用“新建任务”按钮；新建日期只能选今天及以后，选择未来日期后显示在“未来事项”，到了当天自动显示在“今天”。点击标题打开详情。
- “心愿单”专门记录想买电脑、想去旅行等没有固定日期的个人愿望。点击“添加心愿”创建，实现后勾选右侧方框，保留删除线记录并可再次点击撤销；不会移进任务的已完成列表。原收集箱的数据保留在这里。任务截止日期独立于安排日期。
- 到期仍未完成的任务显示红色“超时任务”，优先显示在今天和悬浮窗今日列表；收起的小窗显示“超时 · 标题”。精确截止按时间、纯日期截止按本地当天结束判断；没有截止设置则安排日期过后超时。完成或延后截止后标识自动更新。
- 日期输入支持直接键入；点右侧日历按钮可直接输入年份、切换月份或点选日期，并提供“今天 / 明天 / 一周后”快捷按钮，不必逐月滚动。新建仍只接受今天及以后。
- 子任务可编辑、排序和勾选，保存后计算进度；全部完成不会自动完成父任务。有未完成子任务时完成父任务会要求确认。
- 列表和详情中的删除均需确认，确认后永久移除任务、子任务及提醒，无法撤销；不再提供“已删除”入口。旧版已删除记录保留在数据库中，不批量清理。删除分类只清除任务的分类关联。
- 从侧栏打开悬浮小组件；主界面不再单独显示快速输入入口。小组件默认收起，按任务文字实际宽度、换行高度和条目数自动缩放的小窗，显示今日任务标题，已完成项在原位显示删除线；点击“展开”显示“今日 / 未来事项”页签、日期、进度和快速添加；未来事项按周一至周日分组，点击“收起”回到今日简洁列表；快速输入默认安排到今天，也可选择未来日期及分类，不会自动添加到心愿单。
- 多窗口过期编辑会保留草稿并提示重新载入；保存失败不显示成功。浏览器预览不保存任务，实际使用请启动桌面版。

- Ctrl+Alt+T 打开快速输入，Esc 隐藏；软件设置可修改快捷键，冲突时保留原设置及原有效键；快捷键不可用不阻止悬浮窗显示/隐藏，修改其他设置不会重试未改变的快捷键。
- 悬浮窗标题拖动，右下角缩放；软件设置保存透明度、置顶、显隐及关闭行为，或恢复默认位置。
- 明亮/深色/跟随系统同时同步页面与原生窗口标题栏；左侧品牌和主题区固定，中间导航独立滚动。
- 开机启动默认关闭，仅显式勾选保存后注册。登录后台运行，不强制弹主窗口；请保持 exe 路径稳定。

## 提醒与重复任务

- 详情抽屉可设置指定时间、截止时及提前10/30/60/1440分钟提醒；已到期提醒可在详情或提醒中心稍后10/30/60分钟。取消提醒需保存任务。
- 支持每天、指定星期、指定月日期及自定义天数间隔，结束日期可空；重复需要计划日期，月末不足指定日期取最后一天。
- 编辑重复实例可选“仅此一次”或“此次及此后所有实例”；后者保留完成历史、软删除待替换的未完成实例，再按新模板生成。停止系列可选择“不重复”及“此次及此后”。
- 后台线程复用唯一 LocalService；默认预生成32天，较早提醒扩展范围，分批补齐离线期间实例和到期提醒。关闭主窗口隐藏到托盘后仍运行，完全退出期间不实时提醒。
- 系统通知始终辅以持久化应用内提醒中心。Windows 禁用通知或免打扰可能阻止展示；点击回调受系统限制，通知中心里的旧通知不保证能打开详情。
- 纯日期不做UTC转换；日期截止按本地当天23:59。完成/删除会取消本实例提醒，撤销完成/恢复不会自动重发旧提醒；如需重新提醒，请修改提醒时间后保存。

## 数据管理、日历与周概览

- 软件设置新增“数据管理”：自动备份默认开启，每24小时一次，默认保留最新30份自动备份；可调整1–8760小时周期、1–365份保留量，或立即手动备份。
- 使用SQLite Online Backup API生成完整一致性备份，校验后发布`.db`和`.db.json`清单；手动/恢复前安全备份不自动清理。可查看时间、列表或打开固定备份目录。
- 恢复列表中的备份需要明确确认，将替换全部数据并丢弃各窗口未保存草稿；先创建当前数据库安全备份，再暂停服务、校验/迁移副本、关闭连接、安全替换并重载。文件锁失败会回退或保留恢复日志供下次启动处理。
- JSON完整导出含版本、时间、所有业务/设置/审计表；当前不提供JSON导入。CSV可导出全部任务（含旧软删除记录），带UTF-8 BOM并处理公式前缀。保存位置通过原生对话框选择。
- 左侧新增“周概览”：每周按周一至周日分组，默认本周，可切换上一周/下一周和返回本周；包含完成、未完成和超时统计，支持分类/状态筛选，点击任务打开详情，按当天添加任务。
- 左侧保留月历和周概览，已移除搜索与筛选页面。月历按计划日期归日；没有计划日期时按本地截止日期归日，可点击日期添加任务。只显示实际生成的重复实例，不虚构无限未来实例。
- 详细说明见[数据管理使用说明](docs/data-management.md)。

## 运行

源码现已托管于 [GitHub](https://github.com/ikunyu/TaskDock)。多人开发请阅读 [贡献与协作指南](CONTRIBUTING.md)，从 main 创建功能分支，通过 Pull Request 合并。仓库不包含用户数据、工具链、构建缓存、私钥或凭据；安装包继续通过 Releases 发布。

需要 Node.js 24、Rust MSVC、Visual C++ 构建工具、Windows SDK 和 WebView2。

```powershell
npm ci
npm run tauri -- dev
```

本次开发若使用项目内工具链，先 `. .\scripts\Use-LocalToolchain.ps1`。浏览器布局预览可运行 `npm run dev`；预览不连接数据库，不等同于桌面应用。

## 验证与构建

```powershell
npm run typecheck
npm test
npm run build
cargo test --manifest-path src-tauri/Cargo.toml
cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets -- -D warnings
npm run format:check
cargo fmt --manifest-path src-tauri/Cargo.toml -- --check
npm run tauri -- build --no-bundle
```

执行 `npm run package:windows` 生成Release和NSIS安装包。原生主程序：`src-tauri/target/release/taskdock.exe`。数据库由 Rust 保存在实际EXE目录下的data/taskdock.sqlite3，备份在data/backups；日志和WebView缓存也在EXE旁的logs、webview中。前端没有文件系统或原始SQL权限。请勿删除数据库解决启动问题。

悬浮窗采用窄布局：展开默认240宽、最小180宽，收起按内容自适应且最多200宽。未来事项周标题15px、事项11px；今日/未来已完成项保留原位，可再次点击撤销，重启后仍从数据库状态恢复。

悬浮窗保留原布局和字号，仅收紧边距及间距。展开后按实际内容收缩高度，正常内容范围约120–320逻辑像素，较多任务内部滚动；保存的展开宽度保留，收起继续按内容自适应。

悬浮窗：默认宽180，可手动缩放；展开和收起均提供“今日 / 未来”页签，未来按周分组。收起任务默认14px。在“软件设置 → 外观与桌面 → 悬浮小组件”可分别调整展开任务、收起任务、任务日期/时间、周标题及周日期范围字号，点击“保存桌面设置”生效并记住，主窗口字号不变。

定期提醒同一任务：在任务详情中设置“首次提醒”，勾选“定期提醒同一任务”，可选每30分钟、每小时、每6小时、每天、每周，或自定义分钟/小时/天数。完成、删除或到达完成日期的截止时间后停止。它只提醒当前任务，不生成新任务；“任务重复周期”仍用于生成新任务。日期名称统一为“截止日期”。截止方式保留“无截止 / 仅日期（当天结束前）/ 精确时间（本地时间）”；仅日期沿用上方日期，精确时间使用原来的日期时间选择器，两处日期同步。截止方式位于分类上方，定期提醒功能保留。

数据跟随软件文件夹保存：请将TaskDock放在F、D等非C盘可写目录，或安装时选择该目录；如果软件仍装在C盘，数据也会跟随保存在C盘。首次启动时若新data目录无库，会用SQLite一致性快照迁入旧AppData数据库及备份并保留原文件；已有新目录数据库不覆盖。设置 → 数据管理可查看实际数据目录。移动软件或带任务到其他设备时，先托盘退出，再复制整个软件文件夹（至少含EXE与data），不能只复制EXE。

GitHub更新：启动后自动检查ikunyu/TaskDock的新构建，也可在软件设置 → 关于与运行状态 → 检查更新。下载并验证后，再点击“安装并重启”，先保存所有窗口的草稿。当前软件版本为1.1.1；为兼容已安装的1.0.0更新器，更新协议继续使用1.0.0+内部构建号及原安装包下载别名，内部构建号单独递增。旧设备需先安装一次支持更新的本版本。维护者发布步骤和签名密钥保管见[GitHub更新说明](docs/github-updates.md)。
